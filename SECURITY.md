# Security Policy

## Secrets

Do not commit API keys, access tokens, local databases, logs, or packaged app data. The app stores model provider credentials locally on the user's machine.

## Reporting Issues

If you find a vulnerability, please open a private security advisory on GitHub if the repository supports it. If not, contact the maintainer privately before publishing details.

## Companion Safety

This project is intended for safe companionship and local experimentation. Contributions should avoid manipulative dependency patterns, unsafe identity claims, NSFW content generation, or features that encourage harassment, stalking, or privacy invasion.
